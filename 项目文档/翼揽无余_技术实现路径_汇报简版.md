# 《翼揽无余》Unity MR 项目技术实现路径——汇报简版

## 1. 项目概述

《翼揽无余》是一款面向 **PICO 4 Ultra** 的航空科普沉浸式交互应用。项目使用 **Unity 2022.3.62f3c1** 开发，以手势射线和双手交互为主要操作方式，围绕 C919、直20、歼20和运20四类机型，构建飞机认知、部件学习、爆炸拆解、模拟驾驶、视频课堂和知识测试等体验内容。

## 3. 主要功能

| 功能模块 | 实现效果 |
|---|---|
| 片头展示 | 粒子背景、图片和视频轮播、旁白及进入按钮 |
| 核心交互 | 双手旋转飞机，射线点击部件热点并打开标签 |

| 知识测试 | 图片题目与答案、正误反馈、自动切题及成绩统计 |

## 4. 关键技术

1. **PICO 手势交互**：通过 XR Hands 和 XR Interaction Toolkit 实现手势追踪、远距离射线点击、近距离选择和双手操作。
2. **三维模型交互**：使用 Collider、XR Interactable 和模型旋转根节点，实现整体旋转、热点跟随及零件抓取。
3. **爆炸图系统**：通过完整模型和预拆解模型的状态切换、缓动动画和批量交互配置，实现大量零件的拆解体验。
4. **多媒体系统**：使用 VideoPlayer、RenderTexture、RawImage 和 AudioSource 完成视频、封面、旁白及背景音乐播放。
5. **模块化复用**：先完成 C919 模板，再替换模型、锚点、文案、媒体和题库，扩展至直20、歼20和运20。
6. **移动端优化**：针对 PICO 减少复杂 Collider、透明材质、实时阴影和长期运行的交互组件，重点优化爆炸图场景。

## 5. 项目成果

- 完成公共片头和机型选择流程。
- 完成四类机型的沉浸式学习场景。

- 完成部件认知、爆炸拆解和模拟驾驶等核心体验。
- 完成视频课堂、语音讲解和知识测试闭环。
- 形成可继续复制和替换内容的多机型 Unity 场景模板。
- 通过 PICO 4 Ultra 真机测试，持续修复手势、视频、材质、声音和性能问题。

## 6. 汇报时可以直接这样讲

> 本项目使用 Unity 2022.3 和 PICO XR 技术开发，目标设备是 PICO 4 Ultra。项目以航空科普为主题，包含 C919、直20、歼20和运20四类机型。开发过程中，我们先完成场景规划和模型、图片、视频、音频资源准备，再配置 PICO、OpenXR、XR Hands 和 XR Interaction Toolkit，建立手势射线与双手交互环境。随后以 C919 为基础模板，实现飞机旋转、部件热点、爆炸拆解、模拟驾驶、视频课堂和知识测试等功能，再将稳定的场景结构复制到其他机型并替换对应内容。最后通过多轮 PICO 真机测试，解决了手势点击、视频兼容、透明材质、模型显示、声音播放以及爆炸图性能等问题，形成了一套相对完整、可复用的沉浸式航空学习流程。
